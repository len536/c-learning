# Day 18 · 字符串综合练习：字符分类统计

> 把前面学的遍历、`\0`、字符运算串起来，再加两个小工具：`fgets` 和 `ctype.h`。

## 今日要点

1. **`fgets(str, size, stdin)` 读一整行（含空格）**
   - `scanf("%s")` 遇到空格就停，读不了句子；
   - `fgets` 像「把一行字整端走」，读到换行或装满 `size-1` 个字符为止，最后自动补 `\0`。
   - 它会**把回车 `\n` 也读进来**，统计前通常要手动把末尾 `\n` 改成 `\0`。

2. **`ctype.h` 里的字符判断函数**
   - `isupper(c)`：是否大写字母 A-Z
   - `islower(c)`：是否小写字母 a-z
   - `isdigit(c)`：是否数字 0-9
   - `isspace(c)`：是否空白（空格、制表、换行等）
   - 返回值：是 → 非 0（真），不是 → 0（假）。

3. **综合套路：遍历 + 分流**
   ```c
   for (int i = 0; s[i] != '\0'; i++) {
       if (isupper(s[i]))      upper++;
       else if (islower(s[i])) lower++;
       else if (isdigit(s[i])) digit++;
       else if (isspace(s[i])) space++;
       else                    other++;
   }
   ```

4. **处理 `fgets` 留下的 `\n`**
   ```c
   int len = 0;
   while (s[len] != '\0') len++;        // 手数长度
   if (len > 0 && s[len-1] == '\n')      // 末尾是回车
       s[len-1] = '\0';                  // 抹掉，避免多算一个空格
   ```

5. **生活类比**
   > 字符串扫描就像机场安检：每个字符逐个过闸机，按类型分流——字母去 A 口，数字去 B 口，空格去 C 口，剩下的都归为「其他」。

## 可编译示例

```c
#include <stdio.h>
#include <ctype.h>

int main(void) {
    char s[105];
    int upper = 0, lower = 0, digit = 0, space = 0, other = 0;

    fgets(s, sizeof(s), stdin);            // 读一行，含空格

    int len = 0;
    while (s[len] != '\0') len++;
    if (len > 0 && s[len-1] == '\n')       // 去掉 fgets 带来的回车
        s[len-1] = '\0';

    for (int i = 0; s[i] != '\0'; i++) {
        if (isupper(s[i]))      upper++;
        else if (islower(s[i])) lower++;
        else if (isdigit(s[i])) digit++;
        else if (isspace(s[i])) space++;
        else                    other++;
    }

    printf("upper=%d lower=%d digit=%d space=%d other=%d\n",
           upper, lower, digit, space, other);
    return 0;
}
```
