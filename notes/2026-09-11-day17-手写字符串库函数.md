## 核心要点

### 1. `my_strcpy(dst, src)`：逐字符拷贝，**别忘了补 `\0`**

```c
void my_strcpy(char *dst, const char *src) {
    int i = 0;
    while (src[i] != '\0') {   // 遇到 \0 就停，但 \0 本身还没拷
        dst[i] = src[i];
        i++;
    }
    dst[i] = '\0';  // ← 手动补终止符！漏了就炸
}
```

- `dst` 要够大（至少 `strlen(src)+1` 字节），不然越界写
- `src` 加 `const`：只读不改，防止手滑改了源串
- **指针写法**（更地道）：

```c
void my_strcpy(char *dst, const char *src) {
    while (*src != '\0') {
        *dst = *src;
        dst++;
        src++;
    }
    *dst = '\0';
}
```

### 2. `my_strcmp(s1, s2)`：逐字符比 ASCII，不等就出差

```c
int my_strcmp(const char *s1, const char *s2) {
    int i = 0;
    while (s1[i] != '\0' && s2[i] != '\0' && s1[i] == s2[i]) {
        i++;
    }
    return s1[i] - s2[i];  // 差值：0=相等，>0=s1大，<0=s1小
}
```

- **不是比长度**，是从头逐字符比 ASCII，谁先出现更大的字符谁就大
- `"abc" < "abd"`（c=99 < d=100）
- `"abc" < "abcd"`（前面都一样，s1 先到 `\0`，`\0`=0 < 'd'=100）
- 返回值是**差值**不是 -1/0/1（标准库也是这样，但别依赖具体大小，只看正负）

### 3. `my_strcat(dst, src)`：先走到 dst 尾，再拷 src

```c
void my_strcat(char *dst, const char *src) {
    int i = 0, j = 0;
    while (dst[i] != '\0') i++;   // 走到 dst 的 \0 位置
    while (src[j] != '\0') {      // 从 \0 位置开始接 src
        dst[i] = src[j];
        i++;
        j++;
    }
    dst[i] = '\0';  // 补新的 \0
}
```

- **dst 必须够大**：原内容 + src 内容 + 1 个 `\0`
- 先走到 dst 的 `\0` 处（那是"可接的空位"），再从那儿开始拷
- 如果 dst 空间不够 → 缓冲区溢出，经典安全漏洞

## 生活类比

想象你在抄作业（strcpy）、对答案（strcmp）、续写日记（strcat）：

| 库函数 | 类比 | 关键动作 |
|--------|------|----------|
| strcpy | 把同桌作业**逐字抄**到自己本子上 | 抄完别忘在本末画个"完"字（`\0`） |
| strcmp | 和同桌**逐题对答案**，谁分高看第一个不同的题 | 碰到不一样的题就出结果，不用对完 |
| strcat | 日记本写到一半，**接着往下写**新内容 | 得先翻到上次写完的那页（`\0` 位置） |

## 示例代码（可编译）

```c
#include <stdio.h>

// 手写版
void my_strcpy(char *dst, const char *src) {
    while (*src) {
        *dst++ = *src++;
    }
    *dst = '\0';
}

int my_strcmp(const char *s1, const char *s2) {
    while (*s1 && *s2 && *s1 == *s2) {
        s1++;
        s2++;
    }
    return *s1 - *s2;
}

void my_strcat(char *dst, const char *src) {
    while (*dst) dst++;          // 走到 dst 尾部 \0
    while (*src) *dst++ = *src++; // 接上 src
    *dst = '\0';
}

int main(void) {
    char buf[50] = "hello";

    // strcpy
    char dst1[20];
    my_strcpy(dst1, buf);
    printf("strcpy: %s\n", dst1);           // hello

    // strcmp
    printf("strcmp(hello, hello): %d\n", my_strcmp("hello", "hello"));  // 0
    printf("strcmp(hello, helld): %d\n", my_strcmp("hello", "helld"));  // 正数
    printf("strcmp(helld, hello): %d\n", my_strcmp("helld", "hello"));  // 负数

    // strcat
    my_strcat(buf, " world");
    printf("strcat: %s\n", buf);            // hello world

    return 0;
}
```

## 易错点

1. **strcpy 漏补 `\0`**：循环只拷到 `src[i] != '\0'`，`\0` 本身没拷进去 → 打印越界出乱码
2. **strcmp 比的是字符不是长度**：`"ab" < "b"` 因为 `'a'(97) < 'b'(98)`，跟长度无关
3. **strcat 的 dst 空间不够**：`char buf[5] = "ab"; strcat(buf, "cdefg");` 直接越界写
4. **`while (*src)` 简写**：`*src` 拿到的是 char 的 ASCII 值，`\0`=0 为假自动停；但 `while (*src != '\0')` 更清晰，新手先写清楚版
