# Day 12：字符串库函数

## 核心函数速查表

| 函数 | 功能 | 示例 |
|------|------|------|
| `strlen` | 求字符串长度（不含 `\0`） | `int len = strlen("abc"); // 3` |
| `strcpy` | 复制字符串（包括 `\0`） | `strcpy(dest, "hello");` |
| `strncpy` | 复制前 n 个字符（安全版） | `strncpy(dest, src, 20);` |
| `strcat` | 拼接字符串 | `strcat(dest, " world");` |
| `strcmp` | 比较两个字符串 | `strcmp("a", "b"); // <0` |
| `strchr` | 查找字符第一次出现位置 | `strchr("hello", 'l');` |
| `strstr` | 查找子串位置 | `strstr("hello", "ll");` |

## 手写 vs 库函数
- Day 11 手写了 `my_strlen`，实际开发直接用 `strlen`
- 但面试常考手写版，理解原理

## 踩坑
- `strcpy` 不检查目标空间大小，溢了就崩（安全版是 `strncpy`）
- `strcmp` 返回的不是布尔值，是 `<0 / 0 / >0`

## 类比
> 库函数 = 点外卖，手写 = 自己做饭。面试让你自己做饭，平时点外卖就行。
