## 核心知识点

### 1. 结构体 = 数据打包
```c
typedef struct {
    char name[20];   /* 姓名：19 字符 + 1 个 \0 */
    int  age;
    float score;
} Student;           /* typedef 后直接 Student s; 不用写 struct Student */
```
- 把几个不同类型的变量装进同一个类型，像「设计一张学生卡片有几个格子」

### 2. 函数传结构体：传盒子 vs 传纸条
| 传法 | 写法 | 效果 |
|------|------|------|
| 传整个结构体 | `void f(Student s)` | 复制整个盒子，慢，改不动外面 |
| 传结构体指针 | `void f(Student *ps)` | 给一张纸条（门牌号），轻，能改原件 |

调用时传 `&s`，函数里用 `Student *ps` 接——**跟 Day 6 swap 的思想完全一样**，只不过这次打包的是结构体。

### 3. `->` 箭头访问成员
- `ps->age` 是 `(*ps).age` 的语法糖
- 改成员：`ps->age = 20;` 直接动原件

### 4. 踩坑记录
- **`*ps.age` 优先级坑**：`.` 优先级高于 `*`，会被解析成 `*(ps.age)` → ps 是指针没有 `.age` 成员 → 编译报错。要写 `(*ps).age` 或直接 `ps->age`
- **name 数组不能直接 `=` 字符串**：`s.name = "Tom"` 编译报错（数组名是刻死的地址），要用 `strcpy(s.name, "Tom")`
- **`92.5f` 的 f 后缀**：告诉编译器这是 float 不是 double，不然有隐式转换警告
- **结构体指针必须初始化**（`&stu` 或 malloc），野指针解引用直接段错误

- Day 14（二级指针）的「解引用层数」思想 → 这里 `ps->name` 是「解一层拿盒子，再点格子」
