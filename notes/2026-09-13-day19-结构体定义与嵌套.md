# Day 19 · 结构体定义与嵌套

> 字符串周结束了，今天起进入「结构体」三天。把多个不同类型的数据打包成一个整体——这就是结构体。

## 今日要点

1. **为什么需要结构体？**
   - 之前想存一个学生的信息：`char name[20]; int age; float score;` 三个变量散着放，传递和管理都麻烦
   - 结构体 = 把它们装进一个盒子里，像一张「学生卡片」，一次拿走全部信息
   - 和数组的区别：数组只能装**同类型**数据（全是 int 或全是 char），结构体能装**不同类型**

2. **定义 + 使用三步走**
   ```c
   // 第一步：定义类型（造模具）
   struct Student {
       char name[20];
       int  age;
       float score;
   };

   // 第二步：声明变量（用模具压一个出来）
   struct Student s1;

   // 第三步：访问成员（用 . 点号）
   s1.age = 19;              // 给 s1 的 age 赋值
   strcpy(s1.name, "Tom");   // 字符串成员用 strcpy，别用 =
   ```

3. **`typedef` 起小名**
   - 每次写 `struct Student` 太啰嗦，`typedef` 给它起个短名：
   ```c
   typedef struct {
       char name[20];
       int  age;
       float score;
   } Student;                // 以后直接写 Student 就行，不用带 struct

   Student s1;               // 简洁！
   ```
   - 记法：`typedef` 就是「给类型起小名」，跟给人起绰号一个道理

4. **结构体嵌套**
   - 结构体里可以放另一个结构体，像「大盒子里套小盒子」
   ```c
   typedef struct {
       int year;
       int month;
       int day;
   } Date;

   typedef struct {
       char name[20];
       Date birthday;        // 结构体里套结构体
   } Person;

   Person p;
   p.birthday.year = 2006;   // 连续用两个 . 访问
   ```
   - `p.birthday` 拿到的是里面的 Date 结构体，再 `.year` 才到真正的整数
   - 类比：你寄快递，先填「收件人信息」这一大栏，里面再填「姓名」「电话」「地址」——结构体嵌套就是这种层层填写的结构

5. **结构体初始化**
   ```c
   // 方式一：按顺序赋值（花括号法）
   Student s1 = {"Tom", 19, 88.5};

   // 方式二：部分初始化（没给的自动补 0）
   Student s2 = {"Jerry", 18};     // score 自动 = 0.0

   // 方式三：嵌套初始化
   Person p1 = {"Alice", {2006, 5, 15}};
   ```

6. **生活类比**
   > 结构体就像一张「学生信息表」。你填表时，姓名、年龄、成绩各占一格——这些格子组合在一起就是一张完整的表。嵌套结构体就像表里有一个「家庭信息」小栏，点开又是一个子表。`typedef` 就是给这张表起个简称，不用每次都说「那个有姓名年龄成绩的表」。

## 可编译示例

```c
#include <stdio.h>
#include <string.h>

/* 定义日期类型 */
typedef struct {
    int year;
    int month;
    int day;
} Date;

/* 定义学生类型，里面嵌套日期 */
typedef struct {
    char name[20];
    int  age;
    float score;
    Date birthday;        /* 嵌套结构体 */
} Student;

/* 打印学生信息的函数 */
void print_student(Student s) {
    printf("姓名: %s\n", s.name);
    printf("年龄: %d\n", s.age);
    printf("成绩: %.1f\n", s.score);
    printf("生日: %d-%d-%d\n", s.birthday.year,
           s.birthday.month, s.birthday.day);
}

int main(void) {
    /* 方式一：嵌套初始化 */
    Student s1 = {"Tom", 19, 88.5, {2006, 5, 15}};
    print_student(s1);

    printf("---\n");

    /* 方式二：逐个成员赋值 */
    Student s2;
    strcpy(s2.name, "Jerry");
    s2.age = 18;
    s2.score = 92.0;
    s2.birthday.year  = 2007;
    s2.birthday.month = 8;
    s2.birthday.day   = 20;
    print_student(s2);

    return 0;
}
```
