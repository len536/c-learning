# Day 16 — 字符串逆序（不调库）知识点笔记

> 日期：2026-09-10 · 字符串主线回归第 1 节
> 配套代码：`day16/day16_exercise.c`

## 核心知识点

### 1. 手数字符串长度（strlen 的内部原理）
```c
int len = 0;
while (s[len] != '\0') len++;
```
- 就是 Day 11 `my_strlen` 的单行版——`strlen` 库函数内部就这么干
- "不调库"题的本质：把库函数的手工版写出来

### 2. 头尾双指针原地逆序
```c
for (int left = 0, right = len - 1; left < right; left++, right--) {
    char t = s[left]; s[left] = s[right]; s[right] = t;
}
```
- `left` 从头走、`right` 从尾走，**相遇就停**（`left < right`）
- 循环条件用 `<` 不是 `<=`：相遇时是同一个字符，自己换自己没意义
- 奇数长度：中间字符天然不用动；偶数长度：刚好换完

### 3. `\0` 全程不动
- 逆序只交换 `0` 到 `len-1` 的**可见字符**，`s[len]` 的 `\0` 原地不动
- 交换范围一旦碰了 `\0`，打印就会提前截断或越界——这是本节最大坑

### 4. `scanf("%s", s)` 的边界
- `%s` 遇**空格或换行**就停，所以只读"一个词"，读不到带空格的句子
- `s` 前面**不用加 `&`**——数组名本身就是地址（Day 10：刻死的门牌号）

### 5. 与前后天的连接
- 双指针交换 = Day 14（指针数组）+ Day 6（swap）的组合拳
- 下一节 Day 17 会用 `strcpy/strcmp/strcat` 库函数——今天手写的都是它们的底层

## 易错点
- 循环条件写成 `left <= right` → 中间字符自己和自己交换（结果没错但多一次无意义操作，养成 `<` 的习惯）
- 忘记 `\0` 不参与交换：`right` 初值写成 `len` 就会把 `\0` 换到开头 → 打印出空串
- `scanf("%s", &s)` 加了 `&` → 编译警告，数组名已是地址

## 拓展问题
如果要逆序**一句话**（带空格，如 `hello world c lang`）怎么办？提示：`scanf("%s")` 读不了空格，得换 `fgets` 或循环 `scanf("%s")` 按词逆序再拼——Day 17 见。
